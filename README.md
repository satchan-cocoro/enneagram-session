# エニアグラムセッション 予約システム

60分 7,700円のセッションの、申込から当日までを自動化するしくみです。月額ゼロ。

```
お客さま
  │ ① 空いている日時を選んで申し込む
  ▼
GAS（バックエンド）
  ├ カレンダーに【仮】で予定を入れる（＝この時点で枠が閉じる）
  ├ お客さまへ「お支払いのご案内」メール（PayPalのURL・期限つき）
  └ さっちゃんへ通知（メール＋Discord。どちらにも確定リンクつき）
       │
       │ ② PayPalに入金が入ったのを見て、Discord（かメール）の
       │   「入金を確認した」リンクをタップするだけ
       ▼
GAS
  ├ Zoomミーティングを発行
  ├ カレンダーの【仮】を本予約に更新
  ├ お客さまへ「ご予約確定」メール（Zoom URL入り）
  └ Discordに「確定しました」を投稿
       │
       ▼ 毎朝9時の自動処理
   ・期限が明日に迫った未入金の人に催促を1回
   ・期限を過ぎた仮押さえを自動で開放
   ・明日のセッションの人に前日リマインド
```

## ファイル

| ファイル | 公開URL | 中身 |
|---|---|---|
| `index.html` | `/enneagram-session/` | **LP（セールスページ）**。ここに人を集める |
| `apply/index.html` | `/enneagram-session/apply/` | 予約ページ（日時選択→申込） |
| `legal.html` | `/enneagram-session/legal.html` | 特定商取引法に基づく表記・プライバシーポリシー |
| `satchan.jpg` | — | LPのプロフィール写真 |
| `secrets.local.md` | — | 🔑 DiscordのウェブフックURLなど。**GitHubには上がりません**（`.gitignore`済み） |
| `gas/Code.gs` | — | バックエンド。GASにコピペする |
| `gas/appsscript.json` | — | GASの設定ファイル |

**価格・所要時間・受付曜日・支払いURL・事前質問は、すべて `gas/Code.gs` のいちばん上の `CONFIG` と `QUESTIONS` で決まります。**
ページ側には数字を書いていないので、直すのはここ1か所だけです。

いまの設定：**60分／7,700円／平日10〜15時＋21〜23時／土曜10〜12時／日曜なし**
（申込は48時間先から受付。入金を待つ時間があるためです）

# セットアップ手順

上から順にやれば通ります。所要40分くらい。

## STEP 1 ── PayPalの支払いURL　✅ 設定ずみ

`https://www.paypal.com/ncp/payment/GMXHDH8KTPRVJ`（さっちゃんエニアグラムセッション／¥7,700）を
`gas/Code.gs` の `CONFIG.PAYPAL_URL` に設定済みです。ここは何もしなくてOK。

> ⚠️ **PayPal側の説明文だけ直してください。**
> いまの文面は「zoom IDは自動返信でお送りしております」となっていますが、実際は
> 入金を確認してからZoom URLを送る流れなので、お客さまが支払い直後に不安になります。
> PayPal管理画面 → このリンクの編集 → 説明文を次に差し替え：
>
> ```
> こんにちは！さっちゃんです♪
> この度はエニアグラムセッションにお申し込みいただき、ありがとうございます。
>
> 価格：7,700円
> 方法：オンラインzoom　60分
>
> お支払いを確認しましたら、当日のZoom URLを入れた「ご予約確定メール」を
> お申し込み時のメールアドレスにお送りします。
> （私が手で確認しているので、少しお時間をいただきます。
> 　翌日になっても届かないときは、遠慮なくつついてくださいね！）
>
> では、当日お話しできること、楽しみに待っています！
> ```

## STEP 2 ── Zoomの連携キーを取る

1. https://marketplace.zoom.us/ にログイン →「Develop」→「Build App」
2. **「Server-to-Server OAuth」** を選ぶ（他の種類だと動きません）
3. 名前は「予約システム」などでOK
4. **Scopes** で次の2つを追加：
   - `meeting:write:admin`（見つからなければ `meeting:write`）
   - `user:read:admin`（見つからなければ `user:read`）
5. 「Activate your app」を押して有効化
6. **App Credentials** の3つをメモ： `Account ID` / `Client ID` / `Client Secret`

## STEP 3 ── Discordの通知先　✅ 取得ずみ

ウェブフックURLは受け取り済みです。**`secrets.local.md`**（このフォルダの中・GitHubには上がりません）に、
GASへ貼り付ける形で書いてあります。次のSTEPでそれを使います。

> ⚠️ このURLを知っている人は誰でもそのチャンネルに投稿できます。**SNSやスクショに出さないでください。**
> 外に出てしまったら、Discordのチャンネル設定 →「連携サービス」→ 削除して作り直せばそれで無効になります。

> 💡 ふだんClaudeとやりとりしているDiscordボットとは**別のしくみ**です。
> あのボットはClaudeのセッションが起きているときしか動かないので、夜中の予約を取りこぼします。
> こちらはGASから直接投げるので、24時間動きます。

## STEP 4 ── GASを作る

1. https://script.google.com/ →「新しいプロジェクト」
2. プロジェクト名を「エニアグラムセッション予約」に変更
3. 左の `コード.gs` を全部消して、**`gas/Code.gs` の中身を丸ごと貼り付け**
4. 左メニュー ⚙️「プロジェクトの設定」→「`appsscript.json` マニフェスト ファイルをエディタで表示する」に**チェックを入れる**
5. 左に出てきた `appsscript.json` を、`gas/appsscript.json` の中身に**まるごと差し替え**

## STEP 5 ── PayPalのURLと、ZoomとDiscordのキーを入れる

1. PayPalのURLは設定済みなので、触らなくてOKです
2. `setUpSecrets` 関数を、**`secrets.local.md` に書いてあるコードで丸ごと置き換える**
   （Discordの分は入力済み。**Zoomの3つだけ** STEP2 で取った値に書き換えてください）
3. 上部の関数選択で `setUpSecrets` を選んで「実行」
   - 初回はGoogleの承認画面が出ます →「詳細」→「（安全ではないページ）に移動」→ 許可
   - 自分で書いたスクリプトなので、警告が出て正常です
4. **実行できたら `setUpSecrets` の中の値は消して `'ここに〜'` に戻しておく**
   （キーがコードに残っていると、共有したときに漏れます）

## STEP 6 ── 動作確認（デプロイ前）

- `testSetup` を実行 → 空き枠の数と最初の5件がログに出ればOK
- `testZoom` を実行 → ZoomのURLが出ればOK（テスト用ミーティングが1件できるので、あとで消してください）
- `testDiscord` を実行 → Discordにテスト投稿が入ればOK（**確定リンクは押さないでください**。あとで投稿を消しておく）

空き枠が0件のときは `CONFIG.BUSINESS_HOURS` を見直してください。

## STEP 7 ── デプロイしてURLを取る

1. 右上「デプロイ」→「新しいデプロイ」→ 種類の⚙️で **「ウェブアプリ」** を選ぶ
2. 設定：
   - 次のユーザーとして実行： **自分**
   - アクセスできるユーザー： **全員** ← ここを間違えると予約ページから繋がりません
3. 「デプロイ」→ 出てきた **ウェブアプリURL**（`.../exec` で終わるもの）をコピー

> ⚠️ **あとでコードを直したときの罠**
> 「新しいデプロイ」をするとURLが変わります。ページ側の貼り直しが必要になって事故のもとです。
> 2回目からは必ず **「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→ デプロイ** を使ってください。こちらならURLは変わりません。

## STEP 8 ── ウェブアプリURLをGASに教える

通知メール・Discordに入れる「確定リンク」を作るために、GAS自身にも自分のURLを教えます。

1. `setUpWebAppUrl` 関数の中の `'ここにデプロイして出てきた /exec で終わるURL'` を書き換える
2. `setUpWebAppUrl` を実行

（これはスクリプトのプロパティに保存するだけなので、再デプロイは不要です）

## STEP 9 ── 自動処理をONにする

`setUpTrigger` を1回だけ実行。これで

- 毎朝9時台の自動処理（催促・期限切れ開放・前日リマインド）
- 予約ログのスプレッドシートの「入金確認」チェックボックス連動

の両方が有効になります。ログのスプレッドシートのURLがログに出るので、ブックマークしておいてください。

## STEP 10 ── ページにURLを貼る

**`apply/index.html`** の上のほう（LPのほうではありません）、

```js
const GAS_URL = 'ここにGASウェブアプリのURLを貼る';
```

を STEP7 でコピーしたURLに書き換えます。

## STEP 11 ── GitHubで公開する

1. https://github.com/new でリポジトリを作る
   - 名前は **`enneagram-session`**（公開URLがこの名前になります）
   - Public を選ぶ
2. ターミナルで：

```bash
cd ~/github/enneagram-session && git init && git add -A && git commit -m "エニアグラムセッション予約ページ" && git branch -M main && git remote add origin git@github.com:satchan-cocoro/enneagram-session.git && git push -u origin main
```

3. リポジトリの Settings → Pages → Source を **main / (root)** にして Save
4. 数分後に公開されます

| ページ | URL |
|---|---|
| LP（人を集めるページ） | https://satchan-cocoro.github.io/enneagram-session/ |
| 予約ページ | https://satchan-cocoro.github.io/enneagram-session/apply/ |
| 特商法 | https://satchan-cocoro.github.io/enneagram-session/legal.html |

**告知に貼るのはLPのURL**です。予約ページはLPのボタンから飛びます。

## STEP 12 ── テスト申込を通す（絶対にやる）

自分で最後まで申し込んでみます。**お金は実際には払わなくてOK**です（確定リンクは手で押せるので）。

1. 予約ページを開く → 日時を選ぶ → 入力する → 申し込む
2. 確認すること：
   - [ ] 完了画面にPayPalのボタンと期限が出る
   - [ ] 「お支払いのご案内」メールが届く（PayPalのURLが入っている）
   - [ ] さっちゃん宛に「[入金待ち]」の通知メールが届く
   - [ ] **Discordに「🕐 入金待ちの申込が入りました」が投稿される**
   - [ ] Googleカレンダーに **【仮】** つきの予定が入っている
   - [ ] **同じ枠がもう予約ページに出てこない**
3. **Discord（かメール）の「入金を確認した（確定する）」リンクをタップ**
   - [ ] 「確定しました！」の画面が出る
   - [ ] 確定メールが届き、**Zoom URLが入っている**
   - [ ] カレンダーの【仮】が取れている
   - [ ] Discordに「✅ 予約が確定しました」が投稿される
4. 最後に、テストで作った予定・スプシの行・Zoomミーティング・Discordの投稿を消す

# 毎日の使い方

## 入金が入ったとき（いちばんよく使う操作）

PayPalから入金通知が来たら、**Discordの「🕐 入金待ちの申込が入りました」の中にある「✅ 入金を確認した（確定する）」をタップするだけ**です。
Zoom発行・カレンダー更新・確定メール送信が全部その場で終わります。スマホからでもできます。

同じリンクは「[入金待ち]」の通知メールにも入っています。
スプレッドシート派なら、予約ログの **「入金確認」列のチェックボックスをONにしても同じこと**が起きます。どれでもどうぞ。

## 予約を受けたくない日があるとき

**Googleカレンダーに普通に予定を入れるだけ**でブロックされます。

## キャンセルされたとき

Discord（かメール）の **「🗑 この予約をやめて枠を戻す」** リンクをタップすると、仮押さえが消えて枠が戻ります。
確定済みの予約をキャンセルするときは、カレンダーの予定を削除して、スプレッドシートのステータスを「キャンセル」に書き換えてください。返金はPayPalの管理画面から。

## 受付する曜日・時間を変えたいとき

`CONFIG.BUSINESS_HOURS` を直す → デプロイを管理 → 新バージョン。

```js
1: [['10:00','15:00'], ['21:00','23:00']],  // 月：昼と夜
3: [['10:00','15:00']],                      // 水：昼だけ
4: [],                                        // 木：受付なし
```

## 価格を変えたいとき

`CONFIG.PRICE` を直します。**PayPalのURLも金額入りで作り直して `CONFIG.PAYPAL_URL` を差し替える**のを忘れずに（ここは自動で連動しません）。特商法ページの `legal.html` の販売価格も直してください。

## 支払い期限を変えたいとき

`CONFIG.PAYMENT_DEADLINE_DAYS`（初期値3日）。ただし**セッション開始の24時間前を超えることはありません**（自動で早いほうが採用されます）。

## 事前に聞く質問を増やしたいとき

`QUESTIONS` に1行足すだけ。ページのフォームも確認画面も自動で増えます。
いまは「当日いちばん話したいこと」（必須）と「さっちゃんを知ったきっかけ」（任意）の2つだけです。

## どこから申し込まれたかを測りたいとき

予約ページのURLに **`?from=〇〇`** を付けて配るだけです。お客さまの手間はゼロ、
スプレッドシートの「流入経路」列とDiscord通知の「どこから来たか」に自動で入ります。

| 配る場所 | 貼るURL |
|---|---|
| 公式LINE | `https://satchan-cocoro.github.io/enneagram-session/?from=line`  ← LPに付ける |
| Instagramストーリー | `.../?from=story` |
| Instagram投稿・リール | `.../?from=ig` |
| ポチリプ（自動返信） | `.../?from=pochirep` |
| X（旧Twitter） | `.../?from=x` |
| Threads | `.../?from=threads` |
| オープンチャット | `.../?from=opechat` |
| Substack | `.../?from=substack` |
| note | `.../?from=note` |
| YouTube | `.../?from=youtube` |
| LP・無料講座 | `.../?from=lp` |

キーを増やしたいときは `Code.gs` の `FROM_LABELS` に1行足してください。
未登録のキーが来ても、そのままの文字で記録されるので壊れません。

> 💡 **「どこで知ったか」（フォームの質問）と「どこから来たか」（`?from=`）は別物**です。
> 前者は本人の記憶、後者は実際にクリックされた導線。
> 「Instagramで知ったけど、申し込んだのは公式LINE経由」がふつうに起きるので、両方あると配分を判断できます。

# 気をつけること

- **入金の照合は自動ではできません。** PayPalの固定URLは「誰がどの予約に払ったか」の情報を持てないので、そこだけ目視です。金額とお名前で突き合わせてください。
- **メールは1日100通まで**（無料Gmailの上限）。上限に当たるとメールだけ止まります。
- **Zoom発行が失敗しても確定処理は進みます。** その場合は確定画面に警告が出て、お客さまのメールには「準備でき次第お送りします」と入ります。手動でZoomを作って送ってください。
- **エラーが起きるとさっちゃん宛に `[要確認]` のメールと、Discordに ⚠️ の投稿が飛びます。** 見かけたら必ず中身を確認してください。
- **Discordのウェブフックが失敗しても、予約の処理は止まりません**（メールは届きます）。通知が来ないときは `testDiscord` で疎通を確かめてください。
- 予約ページは `noindex` にしてあります（検索に出ません）。案内は公式LINEやリールから直接リンクを送る想定です。
- 無料個別相談のCalendlyとは別のしくみですが、**カレンダーを共有しているのでどちらかが埋まればもう片方も自動でブロック**されます。
